# 차곡차곡 · 쌓기나무 3D 놀이터

학생들이 블록을 쌓고 여러 방향에서 관찰하는 한국어 3D 시뮬레이터입니다.

[바로 실행하기](https://reiner5427-eng.github.io/stacking-blocks-3d/)

- 7×7 바닥, 최대 8층, 다섯 가지 블록 색
- 짧게 눌러 쌓기·맨 위 블록 삭제
- 마우스 및 한 손가락 드래그 회전, 두 손가락 확대·축소
- 기본 3D·정면·오른쪽·위 시점
- 실행 취소, 전체 비우기, 키보드용 칸 선택판

`index.html`을 내려받아 인터넷 없이도 실행할 수 있습니다. 최신 Chrome, Edge, Safari와 WebGL을 지원하는 기기를 사용하세요. 새로고침하면 블록이 초기화됩니다.

## 배포
GitHub Pages: `main` 브랜치의 루트(`/`)를 게시합니다. 별도 설치나 빌드는 필요하지 않습니다.

## 라이브러리
Three.js r146 및 OrbitControls가 HTML에 포함되어 있으며 MIT 라이선스 고지가 파일에 보존되어 있습니다.
