# LAST BELL · 마지막 종

비례식과 비례배분을 풀어 전기 공격을 발동하는 3분 좀비 생존 게임입니다.

- 실행: https://last-bell-ratio-survival.reiner5427.chatgpt.site
- PC: WASD/방향키 이동, 마우스 사격, 1~3 정답, Space 회피, R 재장전
- 모바일: 왼쪽 조이스틱, 조이스틱으로 바라보는 방향을 정하고 오른쪽 총알 버튼을 길게 눌러 연속 사격. 손을 떼면 마지막 방향을 유지합니다.
- 모바일 세로 화면의 문제 카드는 압축해 표시하며, 접기/문제 보기로 전장 시야를 넓힐 수 있습니다.
- 일시정지 화면에서 종료하면 로비로 돌아가며, 중단한 판은 순위에 등록하지 않습니다.
- 생존자 기록은 Sites D1에 공유 저장합니다. 이름별 최고 점수 상위 200명, 50명씩 4페이지, 1~5위 그랜드마스터, 6~20위 베테랑, 21~50위 다이아, 51~100위 골드, 101~150위 실버, 151~200위 브론즈 배지를 표시합니다. 점수 동점은 처치 수, 생존 시간, 먼저 등록한 기록 순입니다.
- 닉네임은 market-quiz-cat의 한글 포함 2~12자, 영문 금지, 긴 숫자·여러 실명·금지어 규칙을 공유합니다. 숫자를 포함하는 금지어도 원문에서 검사합니다.
- 티어 계급장은 직접 생성한 3×2 투명 PNG 스프라이트를 공유합니다. 순위표의 등급명 옆 아이콘과 펼칠 수 있는 등급표에서 같은 이미지를 표시합니다.
- 모든 티어에 전용 문구와 달성 화면을 표시하고, 결과 화면의 내 랭크 확인에서 개인 최고 기록 기준 현재 순위를 조회합니다. 새로 저장한 최고 기록이 1~5위이면 그랜드마스터 전용 입자 모션과 팡파레가 추가됩니다. 음소거와 모션 줄이기 설정을 따르며, 결과 화면에서 다시 볼 수 있습니다.
- 기록 점수는 클라이언트 전투 결과를 서버에서 범위 검증해 저장합니다. 경쟁용 부정행위 방지 시스템은 포함하지 않습니다.
- BGM은 직접 합성한 MP3 반복 재생, 효과음은 Web Audio를 사용합니다. 외부 음원 다운로드 없이 동작합니다. iOS Safari·Android의 첫 재생은 시작/계속하기 버튼 터치 안에서 호출하고, 차단된 경우 상단 소리 켜기 버튼으로 재시도합니다. MP3는 Safari의 바이트 범위 요청을 지원합니다.

Node.js 24에서 `npm test`로 문항·전투·멀티터치·공유 순위를 검사하고 `npm run build`로 `dist/server/index.js`를 생성합니다. `.openai/hosting.json`의 D1 바인딩은 `DB`이며, `drizzle/`의 SQL을 순서대로 적용합니다. 배포는 기존 Sites 프로젝트 ID를 유지합니다.
